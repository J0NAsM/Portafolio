# Contribuir

## Antes de enviar cambios

1. Usa Node.js 22 (`.nvmrc`) y ejecuta `npm ci`.
2. Ejecuta `npm run build` y `npm test`.
3. No incluyas credenciales, datos de clientes, archivos `.env`, registros ni respaldos.
4. Verifica que textos, enlaces, fechas, métricas y tecnologías sean reales.

## Convenciones

Usa commits breves en imperativo, por ejemplo: `feat: añadir filtro de blog`, `fix: corregir ruta de manifest` o `docs: actualizar despliegue`.

Mantén las mejoras pequeñas y enfocadas. Actualiza `CHANGELOG.md` cuando un cambio afecte a personas usuarias, despliegue, seguridad o mantenimiento.
